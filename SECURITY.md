# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue for a vulnerability, a leaked beta-download
link, credentials, private contact data, or a report that requires sharing
personal photographs or GPS tracks.

Send the report privately through the
[myCamino contact form](https://mycamino.heinofalcke.de/contact/) or email
[mycamino@heinofalcke.de](mailto:mycamino@heinofalcke.de). Include a concise
description, affected beta release, reproduction steps and likely impact. Do
not include secrets unless the developer explicitly requests them through a
secure channel.

The current beta is unsigned and not notarized by Apple. That documented
distribution limitation is not by itself a security vulnerability. Verify the
downloaded DMG against the SHA-256 checksum published on the
[download page](https://mycamino.heinofalcke.de/download/).

Only the current beta release is supported for security fixes.
