# Source Code

The source code for myCamino GPS SlideShow is available at:

https://github.com/hfalcke/myCamino-GPS-SlideShow

Each distributed DMG also contains a source archive made from the exact
working tree used to build that DMG. `Source Code Information.txt` in the DMG
records the Git revision, build date, worktree state, archive checksum, and
upstream repository.

The bundled FFmpeg executable is built from the unmodified upstream source
archive identified in `vendor/ffmpeg/README.txt`. That source archive and its
checksum are included in the DMG.
