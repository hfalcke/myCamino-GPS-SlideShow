# Contributing to myCamino

myCamino is free software and welcomes careful bug reports, feature requests,
documentation improvements and code contributions.

## Reporting a bug

Use the [bug-report form](https://github.com/hfalcke/myCamino-GPS-SlideShow/issues/new?template=01-bug.yml)
for reproducible problems in the current beta. Search the existing issues first
and submit one problem per issue. Include the beta release, macOS version, Mac
model, exact steps, expected result and actual result.

GitHub issues are public. Do not attach private photographs, Adventure folders,
GPS tracks, download-verification links, passwords, email addresses or logs that
contain personal paths or coordinates. Use the
[private contact form](https://mycamino.heinofalcke.de/contact/) when a useful
report cannot be anonymized.

## Requesting a feature

Use the [feature-request form](https://github.com/hfalcke/myCamino-GPS-SlideShow/issues/new?template=02-feature-request.yml).
Explain the practical journey or presentation problem, the desired behavior and
any workaround you currently use.

New submissions receive the `needs-triage` label. The maintainer may request
more information, identify duplicates, apply a milestone or priority, or close a
request that does not fit the project. Removing `needs-triage` means that the
submission has been reviewed; it does not promise implementation.

## Code and documentation changes

Keep changes focused and include tests where behavior changes. Run the relevant
Python tests before submitting a pull request. Large changes should begin with a
feature request so that the intended behavior can be discussed first.

Contributions are accepted under the repository's
[GPL-3.0-or-later licence](LICENSE).
