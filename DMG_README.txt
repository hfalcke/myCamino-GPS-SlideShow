myCamino GPS SlideShow
======================

Installation
------------

Drag myCamino GPS Track Show.app and/or myCamino GPX Editor.app to the
Applications folder. Both applications are self-contained; Python and the
required libraries do not need to be installed separately.

This beta is unsigned and not Apple-notarized. If macOS reports that Apple
cannot check an application for malicious software, dismiss the warning
without moving the app to the Bin. Within about one hour:

1. Open Apple menu > System Settings > Privacy & Security.
2. Scroll down to Security.
3. Find the message about the blocked myCamino app and click Open Anyway.
4. Authenticate and confirm Open.

Approve myCamino GPS Track Show and myCamino GPX Editor separately. Future
launches work with a normal double-click. Only make this exception for a DMG
downloaded from the official myCamino website whose SHA-256 checksum matches
the published release value.

Apple's instructions:
https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac
