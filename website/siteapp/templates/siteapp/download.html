Important before downloading

This beta is unsigned. Recent macOS versions require an extra approval step.

If macOS says Apple cannot check the app for malicious software, this is the expected Gatekeeper warning for this beta. Do not choose Move to Bin if you intend to run myCamino.

  1. Copy myCamino GPS Track Show.app and, if wanted, myCamino GPX Editor.app from the DMG into Applications.
  2. Try to open the app. At the warning, choose Done or dismiss it—not Move to Bin.
  3. Within about one hour, open Apple menu → System Settings → Privacy & Security (Datenschutz & Sicherheit) and scroll down to Security.
  4. Find the message about myCamino and click Open Anyway (Dennoch öffnen). Authenticate, then confirm Open.
  5. Repeat these steps separately for the GPX Editor if you use it. Future launches work with a normal double-click.

Security check: only override Gatekeeper for the DMG downloaded from this website, and compare its SHA-256 checksum with the release card below. See Apple’s official instructions.
