# St-Jean-Pied-de-Port to Roncesvalles Demo

This directory contains the input material for the myCamino guided demo.

- `1 - GPX Track` contains one GPS track.
- `2 - Photographs` contains reduced-quality still photographs associated with
  that stage. Select all of them when the tutorial asks for the photo drop.

The tutorial copies these inputs into a disposable temporary Adventure. It then
uses myCamino's normal metadata and control-file workflow. No generated
sidecars, maps, control file, or Adventure file is bundled here.
